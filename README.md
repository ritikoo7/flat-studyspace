# 📚 FLAT Studyspace

### 🌱 Your Personal Space to Learn, Organize, and Revise

**FLAT Studyspace** is a web-based study dashboard designed to help students prepare for **Formal Languages and Automata Theory (FLAT)**.

It brings syllabus tracking, task management, study notes, revision tools, and focus sessions together in one place.

Whether you're preparing for university examinations, organizing your semester, or revising difficult concepts, FLAT Studyspace helps you build a more structured and productive study routine.

- **Stay organized:** Keep track of the topics you have studied and the ones you still need to cover.
- **Prepare for exams:** Plan revision sessions and focus on difficult concepts.
- **Build consistency:** Use tasks and the focus timer to establish a regular study routine.

- **Learn independently:** Find additional topic explanations through learning resources.

---

## 💡 Recommended Study Workflow

Follow this simple routine to get more out of your study sessions.

1. **Check your syllabus:** Identify the topics you need to study.
2. **Set daily goals:** Add a few realistic study tasks.
3. **Learn a topic:** Use your class notes, textbooks, or learning resources.
4. **Write notes:** Summarize important concepts in your own words.
5. **Test yourself:** Use flashcards and revision tools where available.
6. **Track your progress:** Mark topics as completed after studying them.
7. **Revise regularly:** Revisit difficult topics before your examinations.

> 🌱 **Study tip:** Understanding one topic properly is more valuable than marking ten topics complete without understanding them.

## 🚀 Getting Started

### 💻 Option 1: Download the Project

1. Visit the [FLAT Studyspace GitHub repository](https://github.com/ritikoo7/flat-studyspace).
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.
5. Open the extracted project folder.

### 📂 Option 2: Clone the Repository

Make sure Git is installed on your computer.

Open your terminal and run:

```bash
git clone https://github.com/ritikoo7/flat-studyspace.git
```

Navigate to the project folder:

```bash
cd flat-studyspace
```

### 🌐 How to Open the Website

**Method 1: Open Directly in Your Browser**

1. Open the project folder.
2. Find `index.html`.
3. Double-click the file.
4. The website will open in your default browser.

That's it! 🎉 You can start using FLAT Studyspace.

**Method 2: Open Using Visual Studio Code**

1. Open Visual Studio Code.
2. Select **File → Open Folder**.
3. Choose the `flat-studyspace` folder.
4. Open `index.html`.
5. Preview the website in your browser.

You can use the Live Server extension for local preview, but it is optional.

> **Note:** The current standalone version does not require Node.js, npm, or a backend server.

## 🌐 Deploy with GitHub Pages

You can publish the standalone website using GitHub Pages.

### Deployment Steps

1. Open your [FLAT Studyspace repository](https://github.com/ritikoo7/flat-studyspace).
2. Select **Settings**.
3. Open **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.
8. Wait for the deployment to complete.

Your website URL should look like this:

**https://ritikoo7.github.io/flat-studyspace/**

Check **Settings → Pages** for the deployment status and published URL.

For more information, read the [official GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## 💾 Data Storage and Privacy

FLAT Studyspace uses browser **Local Storage** to save supported study information.

- 📌 Data is stored locally in the browser.
- 🔄 Data does not automatically synchronize between devices.
- ⚠️ Clearing browser storage may remove saved information.
- 💾 Export your data regularly to maintain a backup.

If you use the website on another browser or device, your study data will not automatically appear there.

---

## ⚠️ Current Limitations

- The current version does not include a cloud database or automatic cross-device synchronization.
- YouTube topic buttons open search results rather than necessarily linking to individually verified videos.
- If an AI Study Buddy is included, it may prepare prompts for an external AI assistant rather than connect directly to an AI model.
- Study data stored in Local Storage is limited to the browser where it was saved.
